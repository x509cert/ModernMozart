# Pianos

Every `.sf2` file in this folder ships inside the APK and appears in the app's **piano dropdown**,
listed by the SoundFont's own bank name. Each is played with bank 0, program 0, so use piano-only
SoundFonts (or General MIDI ones, where program 0 is the acoustic grand).

**Piano.sf2** is the default for new installs. After that the app remembers the user's choice.

Currently:

- **Piano.sf2**: *Upright Piano KW* (small), a Kawai upright recorded by Gonzalo and Roberto,
  from [FreePats](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html), CC0 1.0 (public domain).

To add another (e.g. the brighter variant), see [Pianos (SoundFonts)](../../../../README.md#pianos-soundfonts)
for the download links, then add the `.sf2` here under any name, e.g. `Piano-Bright.sf2`.
